The homepage menu, on its own. Same emerald outline, mono line, and [] label. Hover selects the line like code. Press strikes the key. Active is the line that stays.

  • Hovered selection wipe, prompt types, cursor blinks
  • Pressed sinks, flashes, cursor locks
  • Active fill stays, bold, prompt stays
