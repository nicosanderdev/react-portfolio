Explore button

The button in the How I Build intro window. Same size and emerald outline. Hover selects the label and types a prompt. Press strikes the key.

  • Default outline, the word alone
  • Hovered selection wipe, prompt types, cursor blinks
  • Pressed sinks, flashes, cursor locks
  • Active fill stays, bold, prompt stays
